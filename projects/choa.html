Early warning for pediatric ICU transfer

Jun 2025 – Present · Advisors: Dr. Kai Wang, Dr. Gian-Gabriel Garcia · Deployed via Epic EHR API

A model that flags pediatric inpatients likely to need an unplanned transfer to intensive care, built on CHOA's own flowsheet data, benchmarked against the clinical standard PEWS score, and running inside the hospital's Epic workflow.

The problem

Unplanned escalations of care in a children's hospital are rare and costly. The industry-standard tool for spotting them early is PEWS, a hand-computed early-warning score. We asked whether a model trained on the hospital's own EHR data could do better, and whether it could be deployed in a way clinicians would actually trust.

The data is hard in the way real hospital data is hard. Vitals arrive at irregular intervals. Nursing assessments mix structured dropdowns with free text. Positive events are rare: the event rate on the test set is 0.617%.

What I built: a 9-stage preprocessing pipeline

The core technical contribution is the pipeline that turns long-format flowsheet records into model-ready features. Two stages are the interesting ones.

  1. WDL-tree-aware semantic imputation. EHR assessments are hierarchical. When a nurse marks a system as "Within Defined Limits", the sub-measurements underneath (breath sounds, respiratory effort, cough) are clinically implied normal but recorded as missing. Statistical imputation treats them as unknown. The pipeline reads the WDL tree and fills them as normal, which is what the nurse meant.
  2. LLM chain-of-thought severity scoring. Verbose dropdown values ("mild intercostal retractions") were ordinally encoded, which throws away severity gradation. I replaced ordinal codes with a continuous 0–1 severity score generated by an LLM under chain-of-thought prompting at temperature 0, plus age-group-aware normal thresholds. A second version scores five clinical dimensions (severity, urgency, objectivity, salience, trajectory) across 602 unique EHR values, which preserves cases like prone positioning: low severity, high salience.

The remaining stages are feature filtering, outlier removal tuned to keep every true positive, transfer-relative row flagging, time binning, prediction-window labelling for 2-hour and 12-hour horizons, four temporal delta features per variable (since admission, since last measurement, from the patient's own extrema, from the age-group normal), and a final imputation pass.

Models and results

I built and benchmarked a reconstruction-augmented LSTM, the MIST transformer from our NeurIPS submission, a neural network, a decision tree, an isolation forest, and logistic regression with a bagged ensemble, all against PEWS.

Deployment

The bagged logistic-regression model is the one in production, integrated into CHOA's clinical workflow through the Epic EHR API. It was chosen over the stronger transformer for interpretability and lower deployment complexity. I wrote about that decision in Why the weaker model shipped.

I defined the model API contract and payload specification for the Epic FHIR integration inside a cross-institutional team of about 19 people, working PR-based with pre-commit hooks. I presented feature-importance and time-window analyses to CHOA clinical staff, and the 2-hour and 12-hour windows and alert thresholds were iterated on direct physician feedback.
