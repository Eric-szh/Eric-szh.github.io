Course project · CS 7643 Deep Learning, Georgia Tech · Spring 2026

RGB–LiDAR fusion for food macro-nutrient estimation

With Timotheus James, Julien Perez and Jinseok Heo · Dataset: Nutrition5k

Can a depth map make a calorie estimate better? Yes, by 17.6% MAE, but only if the depth encoder is small and trained from scratch. The two things we expected to help most, a big pretrained depth branch and food-classification pre-training, both made it worse.

Setup

Nutrition5k pairs overhead dish photos with structured-light depth maps and dietitian-measured macros. Our working set was 3,242 dishes with valid RGB and depth pairs, predicting calories (extended to fat, carbs and protein). Food-101 (about 101k images) was used for a pre-training ablation.

My part: I built the RGB+Depth V1 and V1-Improved models, which ended up the best architecture overall; designed and ran the Food-101 pre-training pipeline; ran the hypothesis experiments and architecture ablations; and led the error analysis and per-calorie-range breakdown.

Architecture (V1-Improved)

  • RGB stream: pretrained ResNet18, 512-dim embedding.
  • Depth stream: a 4-layer CNN trained from scratch (1 → 32 → 64 → 128 channels, adaptive average pool to 64 dims). Deliberately small: a single-channel overhead depth map has nothing in common with ImageNet.
  • Fusion: concatenate to 576 dims, then a 576 → 256 → 1 regression head.
  • Training: SmoothL1 loss (β = 0.5), AdamW, differential learning rates (backbone 1e-5, head 1e-3), gradient clipping, cosine annealing, depth augmentation (Gaussian noise plus random block dropout), and a log1p target transform with z-score normalisation.

Three hypotheses, two surprises

  1. Depth helps, but only lightweight depth. Swapping the 4-layer CNN for a full ResNet18 depth branch made MAE worse by 8.15 kcal. Pretrained ImageNet filters are the wrong prior for a depth map, and there is not enough data to overwrite them.
  2. Food-101 pre-training hurts. Initialising from a food classifier raised MAE by 6.2%. Category-discriminative features are trained to ignore exactly what portion regression needs: how much of the dish there is, not which dish it is.
  3. The log transform matters more than the architecture. Moving from raw MSE to a log1p target cut MAPE by 15.5 percentage points (46.97% → 31.44%). Raw MSE lets the high-calorie tail dominate and the model over-predicts every light dish.
